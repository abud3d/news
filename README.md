# ذكاء السعودية | Saudi AI

منصة موجز أخبار عربية تركز على الذكاء الاصطناعي والتقنية وأخبار السعودية والمنطقة.

## النسخة الأولية 1.1
- واجهة عربية RTL متجاوبة.
- أقسام للذكاء الاصطناعي والتقنية والاقتصاد والشركات الناشئة وأخبار السعودية.
- فلترة الأخبار حسب المدن السعودية.
- إظهار اسم الناشر الأصلي قدر الإمكان بدلاً من عرض Google News كمصدر للخبر.
- صفحة مستقلة قابلة للمشاركة لكل خبر عبر article.html، مع رابط واضح للقراءة لدى الناشر الأصلي.
- مشاركة الخبر عبر مشاركة الجهاز أو نسخ الرابط.
- ساعة الرياض والتاريخ الهجري ومواقيت الصلاة القادمة.
- تحديث تلقائي للموجز كل 30 دقيقة أثناء فتح الصفحة.

## اللغات والصفحات
- النسخة العربية: `index.html` مع `article.html` و`directory.html` و`services.html`.
- النسخة الإنجليزية: `index-en.html` مع `article-en.html` و`directory-en.html` و`services-en.html`.
- يتشارك الإصداران ملفات البيانات والوظائف والتصميم، مع روابط تبديل اللغة.

## مصادر الأخبار
تُستخدم خدمة RSS كوسيلة تقنية لاكتشاف العناوين، بينما تُعرض بيانات الناشر الأصلي ورابطه. لا يعني ذلك أن Google News هو ناشر الخبر. ستتم إضافة خلاصات مباشرة من الجهات والناشرين الرسميين تدريجياً.

## النشر
يُنشر الموقع عبر GitHub Pages وGitHub Actions عند تحديث فرع main.
