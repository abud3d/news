# عايرف | A'IRIF

موجز أخبار عربي سريع بتصميم ليلي زيتي، مستوحى من بساطة Hacker News مع تصنيفات موضوعية ومدن سعودية.

## النسخة الأولية 1.0
- واجهة عربية RTL متجاوبة.
- تصنيفات: رئيسية، اقتصاد، سياسة، رياضة، تقنية وذكاء اصطناعي، سياحة، تعليم، صحة، طقس، عربي، عالمي، Hacker News.
- فلترة الأخبار حسب مدن ومناطق المملكة.
- ساعة الرياض والتاريخ الهجري ومواقيت الصلاة القادمة، مع إمكانية تغيير المدينة.
- جلب الأخبار من Google News RSS عبر rss2json، وأخبار Hacker News من Algolia.
- تحديث تلقائي كل 30 دقيقة أثناء فتح الصفحة.

## النشر
تمت إضافة GitHub Actions لنشر الموقع إلى GitHub Pages عند كل تحديث على فرع `main`.
من إعدادات المستودع: Settings → Pages، اختر GitHub Actions كمصدر النشر إذا لم يتم تفعيله تلقائياً.

## ملاحظات
- هذه نسخة واجهة أولية؛ لا تحتوي بعد على حسابات مستخدمين أو تعليقات أو تفاعلات محفوظة.
- مواقيت الصلاة والتاريخ الهجري تُجلب من AlAdhan باستخدام طريقة أم القرى (4).
- الأخبار وروابطها تعود إلى مصادرها الخارجية؛ يلزم لاحقاً تطوير طبقة مصادر موثوقة وتصنيف ومراجعة.
